# AGENTS.md

Guidance for AI coding agents working in this repository.

- Treat this as an OSS legal-tech infrastructure project, not a private case file.
- Do not add confidential, personal or client-specific data.
- Do not present generated text as legal advice.
- Prefer structured JSON, schemas and tests over prose-only examples.
- Run `npm test` before proposing changes.
- Keep examples jurisdiction-explicit and source-aware.
- Preserve the MIT license and public educational framing.
