# Security Policy

## Supported Versions

The default branch is supported.

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities involving credentials, private data exposure or workflow execution risks.

Report privately to the maintainer through GitHub profile contact information, or open a minimal public issue that says a private security report is needed without including sensitive details.

## Scope

Security concerns include:

- Credential or token exposure
- Unsafe workflow examples
- Personal or confidential legal data in examples
- Prompt-injection risks in legal document processing examples
- Generated output that could be confused with reviewed legal advice

## Data Handling Expectations

Examples must be synthetic, public-source based or fully redacted. Do not submit client data, private court documents or real case material unless it is already public and lawfully reusable.
