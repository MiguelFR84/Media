# Spanish Legal Automation Kit

Open-source toolkit for Spanish and EU legal-tech automation, focused on structured legal workflows, compliance intake, document processing and AI-assisted legal procedure automation.

## Purpose

Legal-tech developers lack reusable open-source infrastructure for Spanish legal workflows. This project provides schemas, prompts, examples and automation flows that help transform unstructured legal information into structured, machine-readable outputs.

The goal is to make Spanish legal automation easier, safer and more reusable for developers, lawyers and compliance teams building AI-assisted tools.

## Main use cases

- Legal document intake automation
- Spanish civil procedure workflow structuring
- Compliance checklist generation
- Legal data extraction
- n8n workflow examples for legal operations
- AI-assisted document processing
- Structured legal schemas for developers
- Legal-tech prototypes for Spanish and EU markets

## Why this project matters

Most Spanish legal-tech projects recreate the same base infrastructure: intake forms, document classification, procedural checklists, compliance questionnaires and legal data extraction.

This repository aims to provide a reusable open-source foundation so developers can build faster, reduce duplicated work and improve the quality of AI-assisted legal automation.
