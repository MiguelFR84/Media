# Spanish Legal Procedure Automation Toolkit

Open-source toolkit for transforming Spanish legal procedures, compliance workflows and court-process documentation into structured machine-readable schemas.

## Use cases
- Civil procedure workflow automation
- Compliance document intake
- Legal data extraction
- AI-assisted legal-tech applications
- Reusable schemas for developers building legal automation tools

## Why it matters
Legal-tech developers lack reusable open-source infrastructure for Spanish and EU legal workflows. This project provides schemas, parsers, prompt templates and automation examples to reduce duplication and improve quality.
