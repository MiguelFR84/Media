## Eligibility Draft - 500 Characters Max

Early-stage but ecosystem-relevant OSS for Spanish legal-tech automation. Spanish/EU legal workflows lack reusable public schemas, validation examples and maintainer-ready automation. The repo is public, MIT-licensed and active, with structured civil procedure examples, schemas, CI and docs for safe AI-assisted legal workflow development.

## API Credits Draft - 500 Characters Max

Use credits for maintainer automation: PR review, schema/example validation, release checklists, documentation consistency, issue triage and generation of tests for Spanish legal procedure workflows. Credits would support public OSS infrastructure only, not confidential client matters.

## Additional Notes Draft - 500 Characters Max

The project is intentionally safety-focused: examples are public/synthetic, legal advice is disclaimed, data-privacy rules are documented, and human legal review is required for substantive legal content. Codex Security would help review workflow and data-handling examples as the project grows.
