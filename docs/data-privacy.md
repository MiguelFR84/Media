# Data and Privacy

This repository is intended for public legal-tech infrastructure, schemas and synthetic or educational examples.

## Do Not Commit

- Client names, IDs, addresses or private matter details.
- Court documents that are not already public and lawfully reusable.
- API keys, access tokens or credentials.
- Private communications, invoices or case strategy.

## Recommended Practice

- Use synthetic examples.
- Redact personal data before opening issues or pull requests.
- Link to public legal sources instead of copying sensitive documents.
- Keep generated legal content clearly marked as non-advice.

## Legal Notice

The repository provides software and educational examples. It does not provide legal advice and does not create a lawyer-client relationship.
